# Roleplay Application

## Overview
A lightweight, web‑based roleplay platform that lets users create characters, manage storylines, and interact through real‑time chat. Built on modern front‑end technologies—HTML, JavaScript, and Tailwind CSS—with continuous integration via OpenRouter and hosted on GitHub Pages for easy deployment.

## Features
- **Character Creation** – Design unique avatars and assign roles within stories.  
- **Real‑Time Chat** – Instant messaging between participants, supporting both public and private channels.  
- **Story Management** – Organize scenes, save drafts, and track narrative progress.  
- **Responsive UI** – Fully responsive design that works on desktop, tablet, and mobile devices.  
- **Customizable Themes** – Apply Tailwind‑styled themes to match different story tones.  
- **Open Source & CI/CD** – Hosted on GitHub Pages with automated builds and tests via OpenRouter.
